# Panduan Screenshot untuk Laprak

Masukkan screenshot berikut ke laporan praktikum:

1. Struktur folder project di VS Code.
2. Isi file `routes/web.php`.
3. Isi file `app/Http/Controllers/MahasiswaController.php`.
4. Isi file `resources/views/home.blade.php`.
5. Isi file `storage/app/mahasiswa.json`.
6. Tampilan awal aplikasi di browser.
7. Tampilan setelah tombol `Tampilkan Data` diklik.
8. Tampilan route `http://127.0.0.1:8000/data-mahasiswa`.

Urutan paling aman untuk laporan:

1. Screenshot kode route.
2. Screenshot kode controller.
3. Screenshot file JSON.
4. Screenshot tampilan awal.
5. Screenshot hasil data muncul.
6. Screenshot data JSON dari route `/data-mahasiswa`.
